# 给第三方的安装清单（照着走就行）

> 目标：**从零**把 `@dsh-external/dsh-blender-plugin` 装到自己的机器上，并拿到**唯一验收判据** ——
> `curl -sS http://127.0.0.1:9877/doctor` 回 `kind=ok`。全程约 10–15 分钟。
> 每一步都有**自检命令**：卡住就先跑自检，再往下走。

## 0. 前置（5 条，缺一不可）

| # | 需要什么 | 怎么确认 |
|---|---|---|
| 1 | **DSH**（本插件是 DSH 插件，装在 DSH 的 profile 里） | `dsh --version` 有输出 |
| 2 | **GUI 版 Blender**（不是只有 `blender -b`） | 能打开 Blender 窗口 |
| 3 | **Blender 侧 addon** —— 本仓 [`addon/dsh_blender_bridge.py`](../addon/dsh_blender_bridge.py) **或**上游 `MCP for Blender` | 见 §2（两条都能连） |
| 4 | **Node** | `node -v` 有输出 |
| 5 | 端口 **9877**（后端）/ **9876**（addon）空闲 | 见 §5 排查 |

## 1. 拿到插件

```bash
git clone <本仓地址> dsh-blender-plugin && cd dsh-blender-plugin
ls lib/index.js        # ← 有这个文件就**不用构建**（本仓已提交 lib/）
```

> **构建是可选的**：只有你要改 `src/` 时才需要
> `DSH_CHECKOUT=/path/to/dsh-harness bash scripts/build.sh`（要指向一个 DSH 源码 checkout）。

## 2. 装 Blender 侧 addon（二选一）

**A. 本仓附带版（推荐）**

1. Blender → `Edit ▸ Preferences ▸ Add-ons ▸ Install...` → 选 `addon/dsh_blender_bridge.py`
2. 勾选启用 **DSH Blender Bridge**
3. 3D 视图按 `N` →「DSH Blender Bridge」面板 → **Connect**（端口 9876）

**B. 上游原版**：按 [ahujasid/blender-mcp](https://github.com/ahujasid/blender-mcp) 说明装 `MCP for Blender`。

> 两条都行：插件对 addon 标识做了**双名回退**（新名 `dshbb_*` 优先、旧名 `blendermcp_*` 回退）。
> **自检**：`curl -sS http://127.0.0.1:9876` 能连上（或见 §5）。

## 3. 装进 DSH

1. 软链（或拷贝）本目录到 `<你的 profile>/node_modules/@dsh-external/dsh-blender-plugin`
2. 该 profile 的 `package.json`：
   - `dependencies` 加 `"@dsh-external/dsh-blender-plugin": "link:<本目录绝对路径>"`
   - `dsh.profile.bundles` 加 `"@dsh-external/dsh-blender-plugin"`
3. 预演配置：`dsh --profile <profile> --dump-config`（能看到本插件即成功）
4. **重启 DSH**（插件是启动时装载的模块）
5. 重启后**会话技能目录会自动多出 `blender-modeling`**（v2.2.0 起随包注册为 bundled skill，无需下载 / 软链）；让模型用 `skill` 加载它即可确认

## 4. 起 Blender 并验证（**唯一判据**）

```bash
# 推荐：一键拉起 GUI Blender + 自动启用 addon（两种 addon 名字都能扫到）
blender_viewport(op="launch")

# 三条验收，全绿才算装好：
curl -sS http://127.0.0.1:9877/health     # 后端活着
curl -sS http://127.0.0.1:9877/doctor     # ⭐ kind=ok
curl -sS http://127.0.0.1:9877/host/ready # 右侧栏面板的门控：ready:true
```

`/host/ready` 回 `ready:true` 后，DSH 右侧栏会出现「**Blender 视口**」标签页。

## 5. 卡住了先看这张表

| 回执 / 现象 | 含义 | 处置 |
|---|---|---|
| `blender-unreachable` | Blender 没跑，或 addon 没 Connect | `blender_viewport(op="launch")`；或人工按 `N` → Connect |
| `ready:false, reason:"handshake-stale"` | 后端**在 Blender 离线时**启动过 ⇒ 协议探测缓存成了 `fallback`，**不会自动重探** | **重启后端**（`blender_viewport(op="restart")`）—— 此时 Blender 已连上就会重探成功 |
| `main-thread-busy` | 主线程被渲染 / 模态操作占住 | 等它空下来，或改走无头 |
| 后端不可用（9877 连不上） | 后端进程没起来 | `blender_viewport(op="start")` |
| 写操作 409 `leased` | 别的会话持有写租约 | `blender_viewport(op="who")`，别强抢 |
| `value is not lossless JSON` | 插件版本旧（< v0.9.4） | 升级后**重启 DSH** |
| 面板不出现 | 门控 `ready:false`（**设计如此**：通道可用才出现） | 先看 `/host/ready` 的 `reason`，按上表处置 |

## 6. 装完自检（可选，不需要 Blender）

```bash
npm test                              # 离线自检全绿
node tests/protocol_selftest.mjs      # 协议适配（不需要 Blender）
node tests/host_routes_selftest.mjs   # /host 路由判据（需要 Blender 才跑满）
```
